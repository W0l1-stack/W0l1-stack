## How I approach engineering

I like systems that remain understandable after they go live. That means clear workflow ownership, safe retries, idempotency, sensible access controls, useful monitoring, and manual approval where AI should not act alone.

I work across both **client automations** and **software products**, from connecting a CRM to WhatsApp to building the application and database behind a complete workflow.
